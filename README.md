# 🎯 Sample Projects - CLG Deployment Demo

A collection of sample web projects for testing deployment workflows on GitHub Pages / any static hosting.

## 📁 Projects

| # | Project | Description | 
|---|---------|-------------|
| 1 | ✅ **Todo App** | A simple CRUD todo list with local storage |
| 2 | 🧮 **Calculator** | Basic arithmetic calculator |
| 3 | 🌤️ **Weather Dashboard** | Fetches live weather via API |
| 4 | ❓ **Quiz App** | Interactive MCQ quiz with scoring |

## 🚀 How to Deploy

### GitHub Pages (Quick)
1. Go to repo **Settings → Pages**
2. Under "Branch", select `main` and root `/`
3. Your site will be live at:  
   `https://akarshjadi.github.io/samples_clg/`

### Netlify / Vercel (Drag & Drop)
Simply drag the `samples_clg` folder to your Netlify/Vercel dashboard.
