# Operator quick-reference card (K5)

One page, laminated, at every gate, both shifts.

| Situation | Do this | Do NOT |
|-----------|---------|--------|
| Student's QR won't scan | Manual entry, type roll | Send them away |
| Student forgot ID | Manual entry, verify name + photo on screen | Let them through without a record |
| Screen frozen / red | Paper register, call [PHONE] | Restart the tablet yourself |
| Visitor arrives | Visitor flow → host confirmation | Scan them as a student |
| Parent calls about a pass | Check Passes → read status | Promise approval |
| Two students, one device | Scan one at a time, wait for green | Batch scan |
| Alert / incident | Press SOS, call [PHONE], then report in app | Handle it alone |
| Suspected fake QR | Scan it. If denied, call supervisor. | Confront the student |

**The one rule above all others:** if the system is down, the gate still opens — on paper. Availability of the gate beats availability of the software. Every time.
