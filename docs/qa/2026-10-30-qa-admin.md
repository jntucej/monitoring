## 6. UX Improvement Recommendations

1. **Responsive Table Cards for Mobile:**
   - **Finding:** On `/admin/users` and `/admin/support`, standard tabular formats require users to swipe horizontally across multiple columns (1,037px wide table on a 375px mobile screen).
   - **Recommendation:** Implement a responsive card or stacked layout on viewports `< 640px` (Tailwind `sm:` breakpoint), converting table rows into distinct summary cards with badge tags.

2. **Breadcrumb / Role Scope Clarity:**
   - **Finding:** When navigating to routes like `/sysadmin/backup`, the system silently bounces the user back to `/admin/overview` without notification.
   - **Recommendation:** Display an unobtrusive toast notification or modal explaining: *"Access to System Backups is restricted to System Administrators"*, so administrators know why the redirect took place.

3. **Sub-API Navigation & Documentation:**
   - **Finding:** Top-level requests to `/api/admin/users` or `/api/admin/analytics` return 404 because user management uses `/api/users` and analytics is partitioned under sub-endpoints.
   - **Recommendation:** Provide redirect fallbacks or a structured route index at `/api/admin` to facilitate integration testing and third-party developer ergonomics.

4. **Floating Action Button & Bot Visibility:**
   - **Finding:** The bottom-right floating voice action button (`HOLD TO SPEAK`) and bot trigger overlay persistent UI elements in mobile mode.
   - **Recommendation:** Adjust mobile z-index and spacing offsets (`pb-safe`) to ensure the floating bot does not obscure pagination buttons or primary modal action footers on narrow devices.
