# Gate Monitor User Guide

Welcome to the Gate Monitor Campus Access Control Platform.

## 1. Getting Started & Login
- Access the platform via your browser at `https://your-domain.com`.
- Log in using your email/roll number and password, or select SSO / Google / Azure AD authentication.
- Complete 2FA / WebAuthn verification if prompted.

## 2. Gate Operators
- Navigate to `/gate/[gateId]` or `/operator/approvals`.
- Scan student/staff QR codes or RFID credentials using your device camera or turnstile scanner.
- View real-time validation results (`APPROVED` or `REJECTED`) and reasons for rejection.
- If internet connectivity drops, offline mode queues scans and auto-syncs when online.

## 3. Students & Parents
- **Students**: View digital ID card, request gate passes (`outstation`, `emergency`, `local_leave`), and view entry/exit scan history.
- **Parents**: Approve or initiate passes for your ward, track real-time campus presence status.

## 4. Support & Helpdesk
- Raise assistance tickets at `/support` for ID card replacement, gate access issues, or system questions.
