# Gate Operator Quick-Start Guide

**Read time:** 5 minutes

---

## 1. Sign In

1. Open the app → **Operator Portal** (or `/login/operator`).
2. Enter your **Operator ID** (e.g. `OP-001`) and your **PIN**.
3. You land directly on your assigned gate terminal, e.g. **Gate 1 (Main Gate)**.


## 2. The Scanner Screen

| Element | Meaning |
|---|---|
| **Scan QR** | Opens camera to scan a student/staff digital ID |
| **Manual Enter** | Type a roll number when QR/damaged card |
| **Entries / Exits / Campus** | Live counters for today |

## 3. Recording an Entry (IN)

1. Scan or type the ID → photo + details appear.
2. Wait for **Identity Verified** badge (~2 s face-check pause).
3. Press **Entry** under *Confirm Entry*.
4. Green flash = recorded. Counters update automatically.

## 4. Recording an Exit (OUT)

1. Verify identity as above.
2. Choose the correct reason:
   - **Regular** — staff/day-scholar routine exit (no pass needed)
   - **Home Out** — hostel student going home → requires an **approved pass**
   - **Day Out / Leave** — short exits; pass rules shown on the button
3. Buttons marked **No Pass** are locked until a pass is approved.
4. Press the reason button → green flash confirms.

## 5. Manual Entry Desk

If the camera fails: sidebar → **Manual Entry Desk** → type roll → verify → same IN/OUT flow.

## 6. Offline Mode

If the network drops, scans queue locally and sync when back online. Keep scanning normally — do not clear browser data.

## 7. End of Shift

Use **Sign Out** in the sidebar. Never leave the terminal unlocked — the kiosk auto-handles session expiry on next use.
