# Warden Approval Standard Operating Procedure
> **Role Note:** The standalone `warden` role was consolidated into `principal` (2026-11); hostel approvals are handled by `deputy_warden`, `hostel_manager`, and `principal` (`assigned_hostel` / `chief_warden` context).

Hostel approvers must review pass requests under their assigned hostel scope.
- Verify reason, departure and return timestamps.
- For home_out passes, ensure parent consent is verified before granting warden approval.
- In case of emergencies, activate campus lockdown via the supervisor console.
